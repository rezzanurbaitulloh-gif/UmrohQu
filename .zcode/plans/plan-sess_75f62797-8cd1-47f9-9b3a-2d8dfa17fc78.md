## Rencana Perbaikan Admin Panel

### Masalah Utama yang Ditemukan:

**1. Warna Nabrak / UI Tidak Jelas**
- Admin layout pakai warna custom (`bg-dark-emerald`, `bg-mint-light`, `text-cool-grey`, `text-obsidian-black`, `bg-neutral-canvas`) yang **tidak ada** di Tailwind config
- Sidebar hijau tua (`bg-dark-emerald`) bertabrakan dengan white topbar
- Dark mode colors tidak diterapkan karena theme context tidak aktif di admin
- Badge variant `destructive` putih di atas background merah — tidak bisa dibaca
- Chart tooltip dark di atas light background
- Semua halaman admin pakai warna yang tidak konsisten

**2. Halaman Gagal Load Data**
- Semua halaman admin menggunakan `useEffect` di client component untuk fetch Supabase
- Supabase client menggunakan `NEXT_PUBLIC_SUPABASE_ANON_KEY` 
- Kemungkinan besar RLS (Row Level Security) di Supabase memblokir query karena user belum authenticated
- Query yang kompleks (join 3 tabel di transactions) gagal tanpa error handling yang baik
- Tidak ada `await cookies()` pada server untuk session check

### Perbaikan yang Akan Dilakukan:

#### A. Admin Layout (src/app/admin/layout.tsx)
- **Sidebar**: Ganti `bg-dark-emerald` → `bg-white` dengan teks `text-slate-700`, border kanan `border-r`
- **Sidebar active state**: Ganti `bg-mint-light` → `bg-emerald-50 text-emerald-700`
- **Topbar**: Pertahankan `bg-white` dengan border `border-b`
- **Hapus semua warna custom** yang tidak ada di Tailwind
- **Pergilah sidebar navigation** yang konsisten: white bg, slate text, emerald untuk active
- **Fix Search input position** (Badge Bell absolute tidak terposisi dengan benar karena parent tidak relative)
- **Logout**: Fix agar menggunakan server-side client

#### B. Data Fetching Fix (Semua halaman admin)
- **Masalah root cause**: Client-component fetch ke Supabase tanpa authenticated session
- **Solusi**: Ubah dari client-side `useEffect` fetch ke **Server Component** menggunakan `createClient` dari `@/lib/supabase/server`
- Setiap halaman admin akan di-restructure sebagai **Server Component** dengan data fetching di server
- Client interaction (search, filter, sort) tetap pakai client-side state dengan data awal dari server
- Tambahkan error handling yang informatif: jika tabel kosong tampilkan "Belum ada data" bukan "Failed to load"
