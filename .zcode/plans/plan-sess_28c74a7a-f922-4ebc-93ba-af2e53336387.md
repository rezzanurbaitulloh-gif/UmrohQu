# UmrohQu Platform — Implementation Plan (Updated from konteks.md)

## Tech Stack
- **Framework**: Next.js 14+ (App Router, Server Components, Server Actions) + TypeScript
- **Styling**: Tailwind CSS + shadcn/ui
- **Icons**: lucide-react
- **Database**: Supabase (PostgreSQL, Auth, Storage, RLS)
- **Multi-Tenant Engine**: Next.js `middleware.ts` (URL Rewriting berbasis subdomain/custom domain)
- **Font**: Inter (Google Fonts)

---

## Phase 1: Project Setup & Infrastructure
- Init Next.js + TypeScript + Tailwind CSS
- Install: `@supabase/auth-helpers-nextjs`, `@supabase/supabase-js`, `lucide-react`, `shadcn/ui` components
- `.env.local` + `.env.example` dengan credentials Supabase yang diberikan
- `next.config.js` — domain config untuk multi-tenant (umrohqu.com + subdomain *.umrohqu.com)
- Setup Supabase clients: browser, server, middleware
- Setup shadcn/ui (Button, Input, Card, Dialog, Tabs, Select, Slider, Avatar, Badge, Toast, dll)

## Phase 2: Database Schema (Supabase SQL)
### Core Tables:
- **profiles** — Extended user data (extends auth.users, role enum: super_admin | support | billing | travel_vendor | jamaah)
- **travel_vendors** — Data biro travel (user_id ref, nama_brand, ppiu_number, subdomain, custom_domain, status_verifikasi, logo_url)
- **packages** — Paket umroh (vendor_id, nama, deskripsi, harga, durasi_hari, tanggal_keberangkatan, kota_keberangkatan, gambar_url, featured, slug, ppiu_number, maskapai, hotel_bintang, rating, jumlah_terjual, is_promo, promo_harga)
- **package_photos** — Gallery foto per paket (photo_url, urutan)
- **itineraries** — Hari-by-hari itinerary per paket (hari_ke, judul, deskripsi, gambar_url)
- **hotels** — Hotel per paket (nama, kota, bintang, deskripsi, gambar_url, jarak_ke_masjid)
- **flights** — Penerbangan per paket (maskapai, kode_penerbangan, dari, ke, waktu_berangkat, waktu_tiba)
- **bookings** — Booking (package_id, customer_id, nama_lengkap, email, whatsapp, total_harga, dp, metode_bayar, status, nomor_booking, bank_tujuan)
- **jamaah** — Jamaah per booking (booking_id, nama_lengkap, nomor_paspor, masa_berlaku_paspor, hubungan)
- **reviews** — Ulasan & rating (package_id, user_id, rating, komentar)
- **follows** — Follow system (follower_id, following_id, tipe: 'travel' | 'jamaah')
- **bids** — Sponsored listing / bidding (package_id, nominal_bid, status, expired_at)
- **site_settings** — Global CMS (key, value) — untuk logo, favicon, banner, footer, maintenance_mode
- **newsletter** — Email subscriber
- **master_data** — Master maskapai, hotel makkah/madinah, kota keberangkatan (untuk CMS)
- **payment_proofs** — Bukti pembayaran (booking_id, gambar_url, nominal, status_verifikasi)

### Enable:
- RLS policies per role
- Storage buckets: `package-images`, `payment-proofs`, `avatars`, `vendor-logos`
- Auth: Email/Password + Google OAuth
- Triggers untuk auto-create profile on signup

## Phase 7: Server Actions
- `actions/packages.ts` — Fetch, filter, sort packages
- `actions/bookings.ts` — Create booking, add jamaah, upload payment
- `actions/auth.ts` — Sign up, sign in, sign out
- `actions/admin.ts` — Update site_settings, verify vendor, manage master data
- `actions/bids.ts` — Place bid, manage sponsored listings

## Phase 8: Middleware (Multi-Tenant)
- Detect subdomain → route ke `(tenant)/[subdomain]` atau `(main)`
- Auth session handling
- Role-based redirect (jamaah → dashboard/jamaah, vendor → dashboard/vendor, admin → dashboard/admin)
- Maintenance mode check (site_settings)

## Phase 9: Seed Data
- Site settings default (nama, logo, footer, maintenance_mode = false)

## Phase 10: Polish & Visual Design
- **Atmospheric Background**: Dark gradient + subtle star pattern + green ambient glow
- **Glassmorphism**: Frosted glass cards (backdrop-blur, subtle borders)
- **Border Radius**: 20px–24px, soft shadows
- **Green Theme**: Primary `#10B981` (emerald), accents `#34D399`
